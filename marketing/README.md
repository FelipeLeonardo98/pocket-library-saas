# Reel Pocket Library

Abra `pocket-library-reel.html` em tela cheia. O botão **Ativar som** inicia uma
trilha synth original, criada no próprio arquivo, sem uso de música comercial.

O roteiro dura 30 segundos e foi preparado em 9:16. Para publicar, capture a
reprodução em tela cheia ou importe a prévia em um editor de vídeo para exportar
em MP4, mantendo 1080 x 1920, 30 fps e áudio ligado.
